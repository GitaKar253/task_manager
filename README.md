# Task Manager

#### Description: So for my project I decided to create a task manager that could handle adding, editing, deleting, showing, and keeping the history of tasks a person creates while having a user-friendly interface. There was a lot of work put into this, but I also got a lot of help from my dad as well as chatgpt for formatting and styling to make it as user-friendly as I wanted it to be. Though, if I had more time, there would have been other things I would have added, such as reminder bells and automatics deletes for tasks that are already due. But as I didn’t have that kind of time, I stuck to keeping it simple and sweet! So for all my files, I had the main app.py that handled just making the main of the app and giving the user the welcome page using welcome.html, which I programmed to just make a simple welcome for the user describing what the task manager is supposed to be. On the right hand bar I have the register and login bars that the user can use to either sign up or login to their account to access their tasks, where I created the login and register htmls and then created a users.py that I connected to the app.py using blueprints to make sure everything was more organized code-wise with a specific place for all the backend code for the user themselves. For the registering process there were 5 parts the user had to complete, though for the login they only needed to fill in their email and password, to which if I had the chance I may have tried to add a feature where I used the first and last names as a backup incase the user forgot their email or password. After, I created a separate tasks.py as well as the tasks.html and history.html for all the tasks for the user to access. At first I wanted to make the tasks on the sidebar like I did my history, but I decided it would be more clean and user-friendly if I chose to add it to the mainpage when the user logged in or signed in to use, and then just redirect them to the tasks mainpage from history using the top bar task-manager, so I did just that. The main page where all the tasks are kept shows a place to create a new task at the top that takes the title, description, due date, priority, and status of said task, and then when created adds it to the tasks page on the button when you scroll down so you can see all your tasks. With the help of ChatGPT I actually added TOAST to add a green bar that says that a task has been added successfully, and I also did this when I added my edit and delete buttons for the tasks at the bottom. And finally, for everything that is done in the tasks page, whether creating or editing or deleting a task and when, everything is stored into my sqlite3 db file of task_manager that uses three tables. The first table is users, which has all the register and login information, the second being user_tasks, which stores all the task data and helps with the user being able to see all their tasks, and finally the user_activities, which stores activity of the user and helps when it comes to showing the user their history for tasks. And it all looks clean and is user-friendly! That's all. Thank you!
